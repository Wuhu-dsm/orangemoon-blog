<threat_model>
Trust boundaries: browser localStorage to frontend app, frontend to `/api/v1/auth/*`, backend to MongoDB user collection, CLI operator to seed script.

STRIDE register:
- T-01 Spoofing owner identity via public registration. Severity: high. Mitigation: remove public registration route from controller; only CLI seed can create owner/admin users.
- T-02 Token theft from persisted frontend storage. Severity: medium. Mitigation: keep tokens scoped to owner-only flow, clear on refresh failure, avoid visitor auth confusion, and document future hardening.
- T-03 Privilege escalation through unused `@Roles()` metadata. Severity: high. Mitigation: implement `RolesGuard` and ensure protected owner-only features can require `admin`.
- T-04 Weak seeded credentials. Severity: medium. Mitigation: seed command requires explicit email/username/password arguments or interactive env input and enforces password length via validation.
</threat_model>
