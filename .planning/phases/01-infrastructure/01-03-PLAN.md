<threat_model>
Trust boundaries: authenticated owner browser to upload endpoint, multipart parser to filesystem, filesystem upload volume to Nginx static serving.

STRIDE register:
- T-01 Tampering/path traversal through upload purpose or filename. Severity: high. Mitigation: enum purpose validation, generated filenames, no user-controlled path segments.
- T-02 Malware or unexpected file type served publicly. Severity: high. Mitigation: image MIME/extension allowlist and file size limit before returning URL.
- T-03 Unauthorized visitor uploads. Severity: high. Mitigation: JWT auth plus `@Roles('admin')`; no public upload route.
- T-04 Disk exhaustion. Severity: medium. Mitigation: multer max file size and strict single-file endpoint; cleanup/quotas deferred.
</threat_model>
