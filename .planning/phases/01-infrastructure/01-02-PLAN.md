<threat_model>
Trust boundaries: browser to visitor identity endpoint, public requests to global throttler, Nginx proxy to backend IP detection, backend to MongoDB visitor collection.

STRIDE register:
- T-01 Denial of service through repeated login/visitor/upload calls. Severity: high. Mitigation: named stricter throttles and IP + route bucket keying.
- T-02 Privacy leak by showing visitor IP. Severity: high. Mitigation: generated nickname is the only frontend display; IP stays internal for abuse controls.
- T-03 Rate-limit bypass behind proxy. Severity: medium. Mitigation: explicitly choose tracker source and document trust-proxy/Nginx header behavior.
- T-04 Inconsistent error envelope. Severity: medium. Mitigation: preserve `{ code, data, message }` for both 401 and 429.
</threat_model>
