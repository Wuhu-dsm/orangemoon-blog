<threat_model>
STRIDE register:
- T07-01 Elevation of privilege: content UI accidentally calls public endpoints for writes. Mitigation: admin content client uses only `/admin/articles`, `/admin/notes`, and `/admin/projects` for writes per D-28.
- T07-02 Information disclosure: preview creates public URL for drafts. Mitigation: preview is rendered in admin route state from block JSON and never links to public unpublished content per D-25.
- T07-03 Repudiation/destructive mistake: delete action hides content unexpectedly. Mitigation: table actions use a confirmation dialog and soft-delete copy from UI-SPEC per D-23.
</threat_model>
