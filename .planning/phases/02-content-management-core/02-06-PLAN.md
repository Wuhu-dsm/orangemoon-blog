<decision_coverage>
D-02: editor adapter emits editor-native block JSON as the canonical content value.
D-03: editor/preview layer does not introduce persisted Markdown, HTML, or plain text body fields.
D-07: editor image blocks use upload-returned URLs.
D-13: editor capabilities are locked behind a project adapter rather than direct route imports.
D-14: editor adapter covers paragraph, heading, list, quote, code, image, divider, link, video/embed, table, and todo/task blocks.
D-15: BlockNote is used as a mature block editor instead of hand-rolled editor behavior.
D-16: external video/embed blocks are supported without local video upload/transcoding/hosting.
D-24: editor action vocabulary keeps save draft separate from publish/update published.
D-25: preview renders current block JSON inside admin.
</decision_coverage>

<threat_model>
STRIDE register:
- T06-01 Tampering: editor vendor JSON shape changes and corrupts saved content. Mitigation: expose a project `BlockContent` type and fixture set; keep vendor imports behind `ContentBlockEditor`.
- T06-02 Information disclosure: preview reveals unpublished content through public URLs. Mitigation: `ContentBlockPreview` is admin-only and does not generate public preview routes per D-25.
- T06-03 Spoofing/tampering: unsafe link or embed URLs enter content JSON. Mitigation: editor adapter validates allowed URL protocols for links/images/video embeds and keeps local video upload out per D-16.
</threat_model>
