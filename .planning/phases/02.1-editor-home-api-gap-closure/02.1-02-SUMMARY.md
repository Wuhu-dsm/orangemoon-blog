## Task Details

### Task 1: Public Article API Client and React Query Hook

Added `PublicArticle` interface and `fetchPublicArticles` function to `publicContent.ts`, reusing the existing `PublicListResponse<T>` type. The function calls `GET /api/v1/articles` with support for `page`, `pageSize`, `tag`, `category`, and `search` params.

Extended `publicContentKeys` with `articles.all` and `articles.list(params)` query key factories. Added `usePublicArticles(params?)` hook with 5-minute `staleTime` matching the existing public project caching strategy. Both `PublicArticle` and `PublicProject` types are re-exported from the hook module.

### Task 2: Refactor LatestArticles to Live API Data

Removed the entire `Article` type and three-entry hardcoded `articles` array. Imported `usePublicArticles({ pageSize: 3 })` and mapped `data?.items` to the display shape through a `mapArticle` helper:

- `id` from `_id`
- `title` from `title`
- `excerpt` from `summary ?? ''`
- `category` from `category ?? first tag ?? '文章'`
- `date` from `publishedAt ?? updatedAt ?? createdAt`, formatted as `YYYY/MM/DD`
- `cover` from `coverImage` with `ImageOff` icon fallback when missing
- `views` from `viewCount ?? readCount ?? views ?? 0` (honest zero, no fake metrics)

Category badge colors use a deterministic string hash over 8 gradient options. All existing card UI (glassmorphism, hover effects, active overlay, ShowcaseGrid) preserved unchanged.

### Task 3: Loading, Empty, and Error States

Added three explicit states using an IIFE-based conditional rendering pattern inside the section shell:

- **Loading:** Three `SkeletonCard` components inside `ShowcaseGrid`, matching real card dimensions (84px image area + title/excerpt/date skeleton rows)
- **Empty:** Compact "还没有文章，敬请期待" message, centered at 156px height; section shell and "查看全部" link remain visible
- **Error:** Compact "加载失败，请稍后再试" message, same dimensions; no crash, redirect, or retry loops

The section header (sparkle icon, "最新文章" title, "查看全部" link) renders identically across all states.
