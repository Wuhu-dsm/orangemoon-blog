## Decisions Made
- ShowcaseGrid not used for empty/error states — a single centered message card with `h-[156px]` (matching ShowcaseGrid height) preserves layout without forcing grid positioning on a single element
- Error state checked before empty/data states (`isError && !isLoading`) to prevent misleading empty display when API fails
- Amber tint (`border-amber-200`, `bg-amber-50/50`) for error state vs slate tint (`border-slate-200`) for empty state — distinct visual signals so users can differentiate "no data" from "couldn't load"
